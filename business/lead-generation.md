# 🎯 Lead Generation - Генерация лидов

## Описание навыка

OpenClaw может генерировать и квалифицировать лиды, настраивать рекламные кампании и автоматизировать воронки продаж.

## 🎯 Возможности

### 1. Создание лид-магнитов
**Типы лид-магнитов:**
- Чек-листы и гайды
- Бесплатные консультации
- Вебинары и мастер-классы
- Пробные периоды
- Калькуляторы и тесты

**Оптимизация:**
- Цепляющие заголовки
- Чёткая ценность
- Простая форма захвата
- Быстрая доставка

### 2. Настройка рекламных кампаний
**Facebook/Instagram Ads:**
- Таргетинг аудитории
- Креативы и тексты
- A/B тестирование
- Оптимизация бюджета

**Google Ads:**
- Подбор ключевых слов
- Создание объявлений
- Настройка ставок
- Ретаргетинг

### 3. Лендинги и формы
- Структура продающего лендинга
- Оптимизация форм захвата
- A/B тестирование элементов
- Увеличение конверсии

### 4. Квалификация лидов
**Скоринг лидов:**
- Бюджет (есть ли деньги?)
- Авторитет (кто принимает решение?)
- Потребность (есть ли проблема?)
- Срочность (когда нужно решение?)

**Сегментация:**
- Горячие лиды (готовы купить сейчас)
- Тёплые лиды (интересуются, но не готовы)
- Холодные лиды (просто смотрят)

### 5. Автоматизация воронок
- Email-последовательности для прогрева
- Чат-боты для квалификации
- CRM для отслеживания
- Автоматическая передача в отдел продаж

## 💬 Примеры использования

### Пример 1: Лид-магнит
```
Запрос: Создай лид-магнит для фитнес-тренера

OpenClaw:
Название: "7-дневный план тренировок для занятых людей"

Ценность:
- Тренировки по 20 минут
- Не требуют оборудования
- Можно делать дома
- Подходят для любого уровня

Форма захвата:
- Имя
- Email
- Цель (похудеть/набрать массу/тонус)

Доставка: Мгновенно на email + серия из 7 писем с тренировками
```

### Пример 2: Квалификация лида
```
Лид заполнил форму на сайте

OpenClaw (автоматическое письмо):
Привет, [Имя]!

Спасибо за интерес к нашим услугам. Чтобы подготовить для вас 
персональное предложение, ответьте на 3 вопроса:

1. Какой бюджет вы планируете? (до $1000 / $1000-5000 / $5000+)
2. Когда планируете начать? (срочно / в течение месяца / просто смотрю)
3. Кто принимает решение? (я / нужно согласовать / команда)

Это займёт 30 секунд и поможет мне предложить оптимальное решение.
```

### Пример 3: Рекламная кампания
```
Запрос: Настрой Facebook Ads для онлайн-курса по йоге

OpenClaw:
Аудитория:
- Женщины 25-45 лет
- Интересы: йога, медитация, здоровый образ жизни
- Поведение: покупали онлайн-курсы

Креатив:
- Видео с фрагментом урока (15 сек)
- Текст: "Начни практику йоги дома. Первый урок бесплатно!"
- CTA: "Получить бесплатный урок"

Бюджет: $10/день
Цель: Лиды по цене до $5

A/B тест:
- Вариант A: Видео
- Вариант B: Карусель с фото
```

## 🎓 Принципы работы

1. **Качество важнее количества** - 10 горячих лидов лучше 100 холодных
2. **Быстрая обработка** - связаться в течение 5 минут
3. **Персонализация** - индивидуальный подход к каждому лиду
4. **Автоматизация** - использовать CRM и автоворонки
5. **Тестирование** - постоянно оптимизировать кампании

## 📊 Метрики эффективности

- Стоимость лида (CPL - Cost Per Lead)
- Конверсия лендинга
- Качество лидов (% квалифицированных)
- Конверсия лид → клиент
- ROI рекламных кампаний

## 🔧 Интеграции

- Рекламные платформы (Facebook Ads, Google Ads)
- CRM системы (для управления лидами)
- Email-платформы (для прогрева)
- Аналитика (для отслеживания конверсий)
- Чат-боты (для квалификации)
