# 🥗 Nutrition Consulting - Консультации по питанию

## Описание навыка

OpenClaw может выступать в роли AI нутрициолога, составлять рационы и консультировать по питанию.

## 🎯 Возможности

### 1. Составление рационов
- Индивидуальный подход под цели
- Расчёт калорий и БЖУ
- Сбалансированное питание
- Учёт предпочтений и ограничений

### 2. Анализ пищевого поведения
- Выявление нездоровых паттернов
- Эмоциональное переедание
- Формирование здоровых привычек
- Осознанное питание

### 3. Образование клиента
- Основы нутрициологии
- Макро и микронутриенты
- Чтение этикеток
- Мифы о питании

### 4. Поддержка и мотивация
- Постановка реалистичных целей
- Отслеживание прогресса
- Работа с срывами
- Долгосрочные изменения

## 💬 Примеры использования

### Пример 1: Рацион для похудения
```
Запрос: Составь рацион на день для похудения (женщина, 70 кг, цель -5 кг)

OpenClaw:
Калорийность: 1500 ккал
БЖУ: 120г белка / 50г жиров / 150г углеводов

Завтрак (400 ккал):
- Овсянка 50г + ягоды 100г
- Яйца 2 шт
- Кофе без сахара

Перекус (150 ккал):
- Греческий йогурт 150г
- Горсть орехов 15г

Обед (500 ккал):
- Куриная грудка 150г
- Гречка 100г (сухой вес)
- Овощной салат с оливковым маслом

Перекус (150 ккал):
- Яблоко + 20г миндаля

Ужин (300 ккал):
- Рыба 150г
- Овощи на пару 200г
- Зелень

Принципы:
- Белок в каждом приёме пищи
- Овощи и клетчатка
- Здоровые жиры
- Сложные углеводы
```

### Пример 2: Работа с эмоциональным перееданием
```
Клиент: Заедаю стресс, не могу остановиться

OpenClaw: Понимаю, это распространённая проблема. Давай разберёмся:

Шаг 1: Осознание
Перед тем как есть, спроси себя:
- Я действительно голоден? (физический голод)
- Или это эмоция? (скука, стресс, грусть)

Шаг 2: Альтернативы
Если это эмоция, попробуй:
- Прогулка 10 минут
- Дыхательные упражнения
- Позвонить другу
- Записать эмоции в дневник

Шаг 3: Если всё же ешь
- Убери отвлечения (телефон, ТВ)
- Ешь медленно, осознанно
- Наслаждайся каждым кусочком
- Останавливайся при насыщении

Шаг 4: Без самобичевания
- Срыв - это нормально
- Не "всё пропало"
- Следующий приём пищи - новый старт
```

### Пример 3: Развенчание мифа
```
Клиент: Углеводы после 18:00 превращаются в жир?

OpenClaw: Это миф! Разберём:

Факт: Набор веса зависит от общей калорийности за день, а не от времени приёма пищи.

Исследования показывают:
- Время приёма углеводов не влияет на похудение
- Важен общий баланс калорий
- Углеводы вечером могут даже улучшить сон

Что действительно важно:
✓ Общая калорийность
✓ Качество продуктов
✓ Баланс БЖУ
✓ Регулярность питания

Ешь углеводы когда удобно, главное - в рамках калорий!
```

## 🎓 Принципы работы

1. **Индивидуальный подход** - нет универсальной диеты
2. **Баланс, не ограничения** - устойчивые изменения
3. **Образование** - понимание "почему", а не просто "что"
4. **Гибкость** - правило 80/20 (80% здоровой еды, 20% удовольствия)
5. **Долгосрочность** - изменение образа жизни, а не временная диета

## 📊 Метрики прогресса

- Изменение веса и композиции тела
- Уровень энергии
- Качество сна
- Пищевое поведение
- Анализы крови (при необходимости)

## ⚠️ Ограничения

OpenClaw НЕ заменяет врача или дипломированного нутрициолога при:
- Серьёзных заболеваниях
- Расстройствах пищевого поведения
- Беременности и кормлении
- Детском питании
