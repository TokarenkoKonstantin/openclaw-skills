# 🧠 Memory Management - Управление памятью

## Описание навыка

OpenClaw может сохранять и использовать контекст диалогов, предпочтения пользователя и историю взаимодействий для персонализированных ответов.

## 🎯 Возможности

### 1. Conversation History
- Сохранение истории диалогов
- Контекст текущей сессии
- Ссылки на предыдущие сообщения
- Темы и паттерны разговоров

### 2. User Context
- Предпочтения пользователя (язык, стиль, формат)
- Цели и задачи
- Интересы и фокусные области
- Контактная информация

### 3. Long-term Memory
- Факты о пользователе
- Прошлые решения и выводы
- Извлечённые уроки
- Важные даты и события

### 4. Short-term Memory
- Текущая задача
- Контекст сессии
- Временные данные
- Промежуточные результаты

## 💬 Примеры использования

### Пример 1: Сохранение контекста
```
Пользователь: Я работаю над AI-агентом для организации знаний

OpenClaw (сохраняет в память):
{
  "current_project": "AI-агент для организации знаний",
  "project_type": "AI/ML",
  "status": "in_progress",
  "timestamp": "2026-03-24T11:00:00Z"
}

[Через несколько часов]
Пользователь: Как продвигается мой проект?

OpenClaw (извлекает из памяти):
Ты работаешь над AI-агентом для организации знаний. 
Последний раз мы обсуждали это сегодня в 11:00.
Хочешь продолжить с того места, где остановились?
```

### Пример 2: Предпочтения пользователя
```
Пользователь: Отвечай кратко и по делу, без воды

OpenClaw (сохраняет в память):
{
  "communication_style": "concise",
  "preferences": {
    "brevity": true,
    "no_fluff": true,
    "direct": true
  }
}

[Все последующие ответы]
OpenClaw: Кратко, по делу, без лишних слов.
```

### Пример 3: Долгосрочная память
```
Пользователь: Я живу в Челябинске, работаю соло

OpenClaw (сохраняет в память):
{
  "location": "Челябинск, Россия",
  "timezone": "UTC+5",
  "work_style": "solo",
  "team_size": 1
}

[Через недели]
Пользователь: Какое время сейчас подходит для встречи?

OpenClaw (извлекает из памяти):
Ты в Челябинске (UTC+5). 
Сейчас [время]. 
Учитывая твой соло-режим, предлагаю [время].
```

## 🏗️ Архитектура

### Уровни памяти:
```
┌─────────────────────────────────────┐
│     Long-term Memory (LTM)          │
│  - Факты о пользователе             │
│  - Прошлые решения                  │
│  - Извлечённые уроки                │
│  - Сохраняется навсегда             │
└─────────────────────────────────────┘
               ↕
┌─────────────────────────────────────┐
│     Short-term Memory (STM)         │
│  - Текущая задача                   │
│  - Контекст сессии                  │
│  - Временные данные                 │
│  - Сохраняется несколько дней       │
└─────────────────────────────────────┘
               ↕
┌─────────────────────────────────────┐
│     Working Memory (WM)             │
│  - Текущий диалог                   │
│  - Активный контекст                │
│  - Очищается после сессии           │
└─────────────────────────────────────┘
```

### Хранилище:
- **SQLite** - для структурированных данных
- **Vector DB** - для семантического поиска воспоминаний
- **JSON files** - для конфигураций и предпочтений

## 📊 Метрики эффективности

- Точность извлечения контекста
- Релевантность воспоминаний
- Скорость доступа к памяти
- Персонализация ответов

## 🔧 Интеграции

- База данных (SQLite/PostgreSQL)
- Vector database (ChromaDB)
- Файловая система (JSON, YAML)
- API для внешнего доступа
