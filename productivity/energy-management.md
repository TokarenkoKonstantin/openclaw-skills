# ⚡ Energy Management - Управление энергией

## Описание навыка

OpenClaw может помогать пользователям управлять личной энергией, продуктивностью и избегать выгорания.

## 🎯 Возможности

### 1. Анализ энергетических паттернов
- Отслеживание уровня энергии в течение дня
- Выявление пиков и спадов продуктивности
- Рекомендации по оптимальному распределению задач
- Персональный энергетический профиль

### 2. Планирование по энергии
- Распределение задач по уровню энергии
- Сложные задачи → высокая энергия (утро)
- Рутинные задачи → средняя энергия (день)
- Простые задачи → низкая энергия (вечер)

### 3. Техники восстановления
- Микро-перерывы (каждые 25-30 минут)
- Макро-перерывы (каждые 90 минут)
- Дыхательные упражнения
- Рекомендации по отдыху

### 4. Deep Work поддержка
- Планирование сессий глубокой работы
- Защита времени для фокуса
- Устранение отвлечений
- Отслеживание продуктивности

### 5. Предотвращение выгорания
- Мониторинг признаков усталости
- Рекомендации по балансу работы и отдыха
- Напоминания о перерывах
- Советы по восстановлению

## 💬 Примеры использования

### Пример 1: Планирование дня
```
Пользователь: Помоги спланировать рабочий день

OpenClaw: Давай оптимизируем твой день под энергию!

Утро (8:00-12:00) - Пик энергии:
✓ Архитектурные решения (2 часа)
✓ Написание сложного кода (2 часа)
Без встреч, без отвлечений

День (12:00-17:00) - Средняя энергия:
✓ Обед и прогулка (1 час)
✓ Встречи и коммуникация (2 часа)
✓ Code review (2 часа)

Вечер (17:00-18:00) - Низкая энергия:
✓ Документация
✓ Планирование на завтра
✓ Организация задач

Перерывы:
- Каждые 90 минут: 10-15 минут отдых
- Каждые 25 минут: 2 минуты растяжка
```

### Пример 2: Deep Work сессия
```
Пользователь: Нужно сфокусироваться на сложной задаче

OpenClaw: Запускаю Deep Work сессию!

Подготовка:
✓ Выключи уведомления (телефон, мессенджеры)
✓ Закрой лишние вкладки
✓ Приготовь воду
✓ Определи цель: что сделаешь за 90 минут?

Сессия (90 минут):
- Таймер запущен
- Одна задача
- Без переключений
- Полная концентрация

Через 90 минут напомню об отдыхе!

Отдых (15 минут):
- Прогулка или растяжка
- Не смотри в экран
- Восстанови энергию
```

### Пример 3: Энергетический аудит
```
Пользователь: Чувствую усталость, не понимаю почему

OpenClaw: Проведём энергетический аудит. Ответь на вопросы:

1. Сколько часов спишь? (7-8 нужно)
2. Когда последний перерыв? (каждые 90 мин нужны)
3. Сколько часов работаешь без отдыха?
4. Есть ли физическая активность?
5. Как питание? (регулярное?)

Анализ:
❌ Сон: 5-6 часов (мало!)
❌ Перерывы: работаешь 4 часа подряд
✓ Активность: есть
❌ Питание: пропускаешь обед

Рекомендации:
1. Увеличь сон до 7-8 часов (приоритет!)
2. Делай перерыв каждые 90 минут
3. Не пропускай приёмы пищи
4. Добавь короткие прогулки

Попробуй 1 неделю - увидишь разницу!
```

### Пример 4: Предотвращение выгорания
```
OpenClaw (проактивно): Замечаю признаки усталости:
- Работаешь 12+ часов 5 дней подряд
- Пропускаешь перерывы
- Нет выходных

Риск выгорания высокий! ⚠️

Рекомендации:
1. Сегодня закончи в 18:00 (не позже!)
2. Завтра возьми выходной
3. На следующей неделе: макс 8 часов/день
4. Запланируй отпуск

Помни: Продуктивность = энергия × время
Без энергии время не поможет.

Хочешь, помогу спланировать восстановление?
```

## 🎓 Принципы работы

1. **Энергия важнее времени** - 4 часа с высокой энергией > 12 часов в усталости
2. **Персонализация** - у каждого свой энергетический ритм
3. **Проактивность** - предупреждать выгорание, а не лечить
4. **Баланс** - работа и отдых одинаково важны
5. **Устойчивость** - марафон, а не спринт

## 📊 Метрики отслеживания

- Часы Deep Work в неделю
- Качество сна (часы)
- Количество перерывов
- Уровень энергии (самооценка 1-5)
- Признаки выгорания (мониторинг)

## 🔧 Интеграции

- Календари (для планирования)
- Трекеры времени (RescueTime, Toggl)
- Фитнес-трекеры (для сна и активности)
- Напоминания (для перерывов)
